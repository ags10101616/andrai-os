# ANDRAI OS / Agent rules

1. Work only in this private `andrai-os` repository.
2. `feature/os-01` is an isolated visual/architecture preview; do not claim it has live CRM data or authenticated users.
3. Never add secret/service_role keys to Git or client code. No hardcoded customer records, prices or metrics.
4. Do not modify `andrai.com.mx`, ZONERA, 5TAR HOST or the separate `andrai-crm` product.
5. GitHub PR to main only after reproducible install, lint, types, tests, build, security review and owner approval.
6. Keep status truthful: PASS only for commands executed; BLOCKED / NOT RUN otherwise.
7. Supabase writes and user onboarding belong to OS-02, not OS-01.
8. Preserve the Spectral Ember brand: obsidian, warm ivory, graphite, coral, Manrope-like typography; no finance-style green accents.
